Desenvolvimento Web Acessível

Este projeto apresenta práticas de acessibilidade, estrutura semântica, navegação por teclado e boa experiência para diferentes utilizadores.

Recursos implementados

  • Estrutura HTML semântica
  • Navegação por teclado
  • Contraste adequado
  • Formulário com identificação dos campos
  • Responsividade
  • Modo escuro automático

Acessibilidade

A aplicação utiliza elementos semânticos e atributos de acessibilidade para facilitar a navegação por teclado e a interpretação por leitores de tela.
